R-ClaimLab is an open-source Evidence Compiler for reproducible data-science education with R and Quarto. It turns an existing R analysis into a portable lesson whose code, values, visual marks, explanations, and receipts remain linked.

The learner starts with a question and records a prediction before inspecting the result. Next, the browser runs real R through WebR and displays the source command, returned rows, seed, package versions, and artifact hash.

Stable evidence identifiers connect the same observation across a semantic table, a two-dimensional plot, and an optional three-dimensional scene. Keyboard users can select exact evidence without depending on pointer interaction, motion, or WebGL.

The learning companion asks the learner to cite an observation, axis, direction, and limitation. Weak reasoning can be repaired, then transferred to changed data. The final receipt preserves the prediction, evidence choice, explanation, transfer response, and reproducibility checks.

Ten reference lessons cover foundational statistics, data visualization, principal component analysis, regression, clustering, learning analytics, and educational data mining. Authors can adapt data frames and established R analysis objects without reimplementing the statistical methods.

R-ClaimLab keeps R as the analytical source of truth. Its table and precompiled artifacts remain available when WebR or three-dimensional rendering is unavailable. This demonstration shows a practical path from an R result to inspectable learning evidence that educators and contributors can reuse.
