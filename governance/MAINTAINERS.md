# Maintainer and advisory roles

## Current roles

- Project lead: educational design, Evidence Compiler direction, research validation, and grant reporting.
- Core R maintainer: open recruitment. Owns R API, CRAN, CI, releases, and schema review with the project lead.
- Statistical methods advisor: open recruitment.
- R education and assessment advisor: open recruitment.
- Accessibility advisor: open recruitment.

No person is listed as committed until they accept the role in writing. Recruitment records should document expected effort, conflict-of-interest handling, and compensation where applicable.

## Decision rule

Public API and schema changes require approval from both core maintainers. A maintainer cannot approve their own breaking schema proposal alone. Security fixes may be released promptly and reviewed retrospectively within seven days.

## Succession

At least two people must have release access. Every quarterly release rehearses package build, CRAN submission preparation, archive creation, and credential recovery. A departing maintainer provides 30 days notice when possible and transfers open release and security responsibilities.
