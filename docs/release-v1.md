# R-LearnXR release-ready v1

R-LearnXR v1 is a complete, installable open educational infrastructure package within a deliberately bounded scope. It is not a claim that every statistics topic or every institutional deployment is finished.

## Shipped product surface

- A learner-facing course home at `examples/index.html`, generated by `render_course_catalog()`.
- Three executable reference lessons with real R execution, 3D evidence, semantic table fallback, source export, learning receipt, and strict checks.
- A statistics pathway covering data questions, data types, distributions, uncertainty, association, regression, classification, PCA, clustering, communication, and reproducibility.
- Learning analytics and educational data mining blueprints covering event-to-construct reasoning, descriptive analytics, feedback/intervention, feature engineering, pattern discovery, prediction, and ethics.
- A stable lesson manifest, course catalog, scene contract, and learning-receipt contract.
- Contributor and educator materials: authoring template, micro-lessons, educator guides, answer key, rubric, accessibility alternative, and extensions.
- Browser-local progress and exports. No login, LMS, telemetry, or private data upload is required for the core product.

## Release gates

The public release is accepted only when all of the following are green:

1. `R CMD check` and package tests on Ubuntu, Windows, and macOS.
2. Strict checks and Quarto renders for every executable reference lesson.
3. Clean installation from public GitHub `main` in a disposable library.
4. Browser interaction, mobile overflow, keyboard, semantic-table, and offline-fallback smoke tests.
5. A generated course-home screenshot at desktop and mobile widths.
6. No secrets or learner identifiers in the repository or generated receipts.

## External evidence gates

These are intentionally not faked by automation:

- A novice learner pilot and an R educator review.
- NVDA, VoiceOver, or JAWS with a real assistive-technology setup.
- A real Posit Cloud or Workbench account rehearsal if that deployment is promised.

The CI persona, accessibility-tree proxy, and clean-room Posit proxy are regression evidence. They do not substitute for those external gates.

## Definition of done for this grant-sized product

The v1 product is done when a learner can enter through the course home, complete an executable lesson, use R or the semantic fallback, export inspectable evidence, and return later with browser-local progress; when an educator can scaffold or validate a lesson from the documented contracts; and when a reviewer can reproduce the package and inspect the evidence from the public repository without the developer's desktop.
