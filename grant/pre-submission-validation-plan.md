## Gate 3: Short structured pilot

Minimum pre-submission evidence is one completed learner or instructor session. This is a usability and feasibility check, not an effectiveness study.

Suggested 20-minute task path:

1. Open the beginner guide and identify the RStudio installation route.
2. Run the starter commands to open or render a lesson.
3. Complete Predict, Run R, Explore, and Explain in one reference lesson.
4. Use the semantic table or keyboard path once.
5. Export or inspect the reproducibility receipt.
6. State what was confusing, useful, and necessary before classroom adoption.

Record only: persona and prior R experience, task completion, elapsed time, errors, facilitator interventions, accessibility path used, and the disposition of each observed barrier. Do not claim learning gains from this session. Obtain the appropriate consent or administrative determination before collecting identifiable research data.
