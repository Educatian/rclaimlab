# Educational data mining: discover patterns responsibly

An executable R-ClaimLab lesson about standardized feature spaces, k-means initialization, centroid distance, stability, uncertainty, and ethical use. The dataset is synthetic and supports methodological critique rather than learner classification.

The method contract makes scale, requested `k`, seed, 25 random starts, cluster size, separation, and the still-unresolved sensitivity across alternative `k` values visible to the learner.

Run `quarto render`, open `scene/index.html`, and run `rclaimlab::check_lesson(".", strict = TRUE)` before adapting the lesson.
