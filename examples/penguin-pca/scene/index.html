The lesson reads one data frame. label names a point; x, y, and z become its coordinates.

Explain this R pipeline
  1. Create a small data frame with labels and numeric axes.
  2. Use scale() to put each axis on a comparable scale.
  3. Use subset() to keep points that meet the filter rule.
