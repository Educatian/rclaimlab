# Accessible Alternative — Penguin PCA

The lesson objective does not require 3D vision, mouse control, color discrimination, or a headset.

## Table-first route

1. Open **Accessible data table and point selector**.
2. Select a row using keyboard focus.
3. Read the `label`, `x`, `y`, and `z` values.
4. Use the explanation sentence frame with one coordinate.
5. Select a second row and complete the transfer comparison.

## Screen-reader wording

Read a coordinate as “PC1 negative zero point three two; PC2 near zero; PC3 positive zero point four eight.” Do not ask a learner to infer depth, color, or spatial proximity from the canvas.

## Low-vision and motor alternative

Use browser zoom and the table export. The static R/Quarto source and learning receipt preserve the same analytical evidence. Keyboard focus remains visible and the scene is progressive enhancement.

## Assessment equivalence

The table route earns the same rubric evidence as the 3D route. Do not reduce the score because a learner chose the accessible path.
