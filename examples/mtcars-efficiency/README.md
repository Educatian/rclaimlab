# Vehicle efficiency data space

This reference lesson was generated by R-ClaimLab from the built-in `mtcars` dataset.

## Reproduce

Run `quarto render`, then run `rclaimlab::check_lesson(".", strict = TRUE)`. The scene uses standardized `mpg`, `hp`, and `wt` coordinates and keeps the source R transformation visible in the lesson.

See [educator-guide.md](educator-guide.md) for prompts, assessment, accessibility, and the regression extension path.
