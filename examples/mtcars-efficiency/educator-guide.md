# Educator Guide — Vehicle Efficiency

## Purpose

Use this 15-minute lesson to teach standardization, association, comparison, and responsible communication before introducing regression or EDM features.

## Facilitation prompts

- “What does a positive standardized value mean here?”
- “Which pair of variables moves together, and what would correlation not prove?”
- “Where is the trade-off instead of a single winner?”
- “What additional data would you need before making a causal claim?”

## Suggested assessment

Use the reusable rubric in `../penguin-pca/assessment-rubric.md`. Require a vehicle label, coordinate, comparison, association wording, and limitation.

## Extension path

Move from `cor()` to `lm()`, inspect residuals, then compare model error with the original visual claim. Keep the table and source export available for all learners.
