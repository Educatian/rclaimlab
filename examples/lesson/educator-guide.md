# Educator Guide — Reference Lesson

## Purpose

Use this 10-minute lesson to teach the R-LearnXR interaction contract before a domain lesson. It is intentionally small and synthetic.

## Facilitation sequence

1. Ask learners to define one row and predict a filter result.
2. Have them identify the input file, coordinate mapping, and seed in the R code.
3. Require a point selected through the scene or table.
4. Use the claim/evidence/limitation sentence frame.
5. Change one rule and ask learners to transfer the reasoning.

## Success evidence

A learner is ready for a domain lesson when they can identify the scene contract, cite a coordinate, and explain why a visualization alone is not a causal claim. Use the rubric in `../penguin-pca/assessment-rubric.md`.

## Accessibility

Start with the semantic table for learners who prefer text, keyboard, magnification, or screen-reader-compatible interaction. The visual scene is optional.
